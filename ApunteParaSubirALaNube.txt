-- Crear el repositorio en GitHub y conectarlo
  En GitHub e iniciar sesión con tu nuevo usuario.
  Crea un nuevo repositorio (botón New arriba a la derecha).

  Ponerle un nombre al repositorio. No marcar la casilla de añadir un archivo README, .gitignore o licencia (ya que los tienes configurados localmente). Haz clic en Create repository.

  GitHub mostrará una serie de comandos. Copia los que corresponden a "Push an existing repository from the command line". Son estos dos (reemplaza la URL por la de tu repositorio):

  # Vincular tu repositorio local con el remoto en GitHub
  git branch -M main
  git remote add origin https://github.com/tu-nuevo-usuario/nombre-de-tu-repo.git

  # Subir tu código a GitHub
  git push -u origin main
